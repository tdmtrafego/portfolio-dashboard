# Painel de Tráfego (versão de portfólio)

Dashboard executivo de performance de marketing que junta Google Ads, Meta Ads e CRM (Kommo) numa visão só: KPIs, saúde da operação, funil do clique até a venda, gargalos detectados automaticamente, campanhas, criativos e vendas.

**Ver online:** https://tdmtrafego.github.io/portfolio-dashboard/

Os números são reais (julho/2026). O cliente foi anonimizado: nomes de campanhas, anúncios, leads e vendedores foram trocados por códigos e os criativos foram borrados. A página é um arquivo estático, sem conexão com nenhuma API.

Desenvolvido por Thiego Dantas.
